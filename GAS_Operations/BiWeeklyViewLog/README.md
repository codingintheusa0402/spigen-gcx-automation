# BiWeekly View Log

Tracked link for the Bi-Weekly deck: an Apps Script web app (executeAs deployer, access = spigen.com) that embeds the deck and logs each open to sheet `1NSMiMwz…` (Visits: who/when/last activity/minutes; Summary: per-person count/total/avg/last). Heartbeat every 30s while visible.
